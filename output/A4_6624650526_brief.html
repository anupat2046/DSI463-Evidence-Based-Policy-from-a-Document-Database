04   คัดรายชื่อด้วย MongoDB query เดียว

ใช้กับ mso_member เพื่อสร้างคิวตรวจสอบในจังหวัด 58 ทั้งสองอำเภอ; เจ้าหน้าที่ตรวจเอกสารและสิทธิก่อนดำเนินการ ส่วนการจัดลำดับเยี่ยมบ้านใช้ผล household join ใน Q2

from datetime import datetime
target = {
  "province_code": "58", "vital_status": 1,
  "status": {"$ne": "removed"},
  "birthdate": {"$lt": datetime(1965, 1, 1)},
  "$expr": {"$gte": [{"$dateDiff": {
    "startDate": "$birthdate",
    "endDate": datetime(2024, 6, 30),
    "unit": "year"}}, 60]},
  "welf_eldery.code": {"$ne": "WFEL9"}
}
db.mso_member.find(target)

query ตรงกับ notebook และ Bonus A2 ใช้อายุแบบขอบเขตปีตามสูตรโจทย์ ไม่ใช่อายุครบวันเกิด เมื่อใช้งานจริงต้องเปลี่ยนเป็นวันตรวจสอบปัจจุบันและตรวจวันเกิดจริง; sensitivity ทั้งฐานให้ 223/1,440 คน เมื่อใช้อายุครบวันเกิด ณ 30 มิ.ย. 2024 เทียบกับ 243/1,461 ตามสูตรโจทย์
